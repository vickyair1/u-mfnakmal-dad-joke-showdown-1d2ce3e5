Entry for the [Dad Joke Showdown](https://make.fun/competitions/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on [make.fun](https://make.fun): one original dad joke, at most 200 characters, judged pairwise by an AI judge on which joke earns the bigger groan.

## The joke

> I told my wife she should embrace her mistakes. She hugged me.

62 characters. A clean pun — *embrace* lands as a hug — with a misdirecting twist: the mistake she embraces is him. Tight, punchline at the end, reads naturally aloud across a dinner table.

## Run

```sh
python3 main.py
```

Deterministic: no randomness, no network, no input. Prints the joke to stdout (identical bytes on every run); `entry.txt` holds the exact same text.

# Dad Joke Showdown — Wi-Fi 404

> "My dad renamed our Wi-Fi '404 Not Found' so guests would stop asking for the password. Now the neighbours think we moved out."

One original dad joke (125 chars), delivered as a deterministic Python program.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it to stdout.
